> **מאגר תצוגה.** זהו עותק סטטי ומנוקה של דף נחיתה שרץ בפרודקשן על הדומיין של החברה. הוסרו ממנו מנהל התגים, החיבור ל-CRM לקליטת לידים, תוסף הנגישות החיצוני וכל מספרי הטלפון האמיתיים. הטופס עדיין מבצע ולידציה, אבל לא שולח כלום: שליחה תקינה מציגה רק הודעת הדגמה.

---

## 📖 מה זה

דף הנחיתה לתנועה ממומנת של אפוסתרפיה, טיפול לא ניתוחי בכאבי ברכיים, גב, ירך וקרסול. יש לו תפקיד אחד: להפוך קליק על מודעה לבדיקה חינם במעבדת ההליכה, וכל מה שבו משרת את זה: כותרת עם הבטחה, שבע נקודות הוכחה, לוגואים של קופות החולים, סרטון, יתרונות הטיפול, ותמיד בהישג יד טופס קצר.

זה הדף הראשון בסדרה. [הדף המחקרי](https://github.com/galasulin/apostherapy-research-landing) ו[סיפור הגלילה של Apos 4](https://github.com/galasulin/apos4-scroll-landing) הגיעו אחריו ומשתמשים באותם שדות טופס ובאותו צינור לידים.

## ✨ מה מיוחד בו

| | |
|---|---|
| **הטופס לא יוצא מהמסך** | במחשב הדף בנוי משתי עמודות: התוכן נגלל, וטופס הלידים יושב בעמודה בגובה מלא עם `position: sticky`. אפשר להשאיר פרטים בכל עומק גלילה בלי לחפש כפתור. |
| **פס פעולות בנייד** | בטלפון הטופס הופך לשכבה במסך מלא, שנפתחת מפס קבוע בתחתית עם שתי פעולות: *השארת פרטים* ו*חיוג עכשיו*. בפרודקשן כפתור החיוג הופיע רק בשעות פעילות המוקד (א-ה 08:00-18:00, ו 08:00-13:00). |
| **מעקב שיחות לפי מקור תנועה** | בפרודקשן, דף ה-PHP בחר את מספר הטלפון שמוצג למבקר לפי מקור הפרסום בכתובת, כך שכל שיחה שויכה לקמפיין שלה, ומקור אחד יכול היה להסתיר את אפשרות החיוג לגמרי. (הוסר בעותק הזה.) |
| **הגדלה נאמנה לעיצוב** | המידות מוגדרות ב-`vw`, כך שפריסת המחשב גדלה ביחס לחלון ושומרת על הקומפוזיציה של העיצוב בכל רוחב; פריסת נייד נפרדת מסדרת מחדש את נקודות ההוכחה עם `order`. |
| **טופס מוקפד** | תוויות צפות ב-CSS בלבד (`:placeholder-shown`), כפתורי בחירת אזור בסגנון גלולה, תיבת הסכמה לדיוור, ולידציה לשם מלא / טלפון / מייל עם אזהרות במקום, ו**שדה מלכודת** נסתר שמסנן בשקט שליחות של בוטים. |
| **שליחת לידים שמודה בכישלון** | בפרודקשן השליחה הגיעה ל-CRM עם העברת UTM, ניסתה שוב פעם אחת בתקלת רשת, החזירה את הכפתור והציגה הודעת שגיאה ידידותית אם עדיין נכשלה, ודחפה אירוע *כישלון* למנהל התגים כדי שתקלה בחיבור תופיע בדוחות ולא תיראה כמו יום שקט. |
| **מעבר נגישות** | קישור דילוג, מסגרות פוקוס בולטות, `role="radiogroup"`, אזהרות עם `aria-live`, אזורי מגע של 44 פיקסלים, צבע שגיאה בניגודיות AA, חלופת `noscript` ו-`prefers-reduced-motion`. |
| **ביצועים + SEO** | לכל תמונה מידות מפורשות והן נטענות בעצלות מתחת לקפל, הלוגו נטען עם `fetchpriority="high"`, ובפרודקשן הדף כלל גרף JSON-LD וכרטיסי Open Graph / Twitter. |

## 🛠️ טכנולוגיות

- **HTML5 + CSS3** (flex/grid, ‏`position: sticky`, יחידות viewport, תוויות צפות ב-CSS בלבד) עם הגופן **Heebo** מ-Google Fonts.
- **JavaScript נקי** בעותק הזה (`demo-form.js`). בפרודקשן סקריפט הלידים השתמש ב-jQuery.
- בפרודקשן: דף PHP עם מפת מספרי מעקב בצד השרת, מנהל תגים וחיבור CRM לקליטת לידים (כולם הוסרו כאן).

## 👤 התפקיד שלי

תכננתי ובניתי את הדף: הפריסה וההתנהגות שלה במחשב ובנייד, הטופס והוולידציה שלו, שליחת הלידים ל-CRM עם שיוך מקור ודיווח על כישלונות, לוגיקת מעקב השיחות, ומעבר הנגישות והביצועים שנעשה בהמשך.

## 📌 סטטוס

**באוויר בפרודקשן על הדומיין של החברה.** המאגר הזה הוא עותק מנוקה לתיק עבודות: המדידה הוסרה, הטופס מנותק, ומספרי הטלפון הוחלפו ב-`*0000` מזויף שמציג רק הודעת הדגמה. הדף מסומן `noindex` כדי שלא יתחרה בדף החי בחיפוש.

## 🔒 פרטיות / מה הוסר

| מה הוסר / הוחלף | איך |
|---|---|
| מנהל התגים, ה-iframe ב-`noscript` וכל אירועי `dataLayer` | הוסרו |
| החיבור ל-CRM, מפתחות הטופס, העברת UTM / מקור והשליחה הכפולה לשותף (‏`script.js`) | הוחלפו ב-`demo-form.js`: אותה ולידציה, בלי שום בקשת רשת |
| jQuery מ-CDN ציבורי | הוסר (סקריפט ההדגמה כתוב ב-JS נקי) |
| מפת הטלפונים בצד השרת (מספר מעקב לכל מקור) ולוגיקת שעות המוקד | הוסרו; כפתור החיוג הוא `*0000` מזויף שלא ניתן לחייג אליו (בלי קישור `tel:`) ומציג הודעת הדגמה |
| מספר כוכבית וקישור וואטסאפ בחלופת ה-`noscript` ובהודעת השגיאה | הוחלפו בהודעת ההדגמה |
| תוסף נגישות חיצוני (עם מפתח האתר שלו) | הוסר |
| הצהרת נגישות עם פרטי קשר של עובדים ופרטי סניפים | לא הועתקה; במקומה `accessibility.html` בלי פרטים אישיים |
| נגן YouTube מוטמע | הוחלף בתמונה שנטענת בלחיצה; שום דבר לא נטען מ-YouTube עד שלוחצים על הפעלה |
| נתונים מובנים עם טלפון החברה | הוסרו |
| כתובות canonical ו-Open Graph | מצביעות על עותק ה-GitHub Pages הזה; הדף מסומן `noindex` |
| קישורים לאתר החברה (פרטיות, צור קשר) | מנוטרלים ומציגים הודעת הדגמה |
| בלוק מבצע ישן שהיה בהערה וה-CSS/התמונה שלו, ‏`robots.txt`, ‏`sitemap.xml`, ‏`404.html`, הגדרות שרת, צילומי מסך ישנים, קובץ ה-PDF | לא הועתקו |
| מטא-דאטה של תמונות (EXIF / XMP / טקסט) | נוקתה מכל התמונות |
